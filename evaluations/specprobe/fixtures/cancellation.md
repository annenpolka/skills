# サブスクリプション解約仕様 v1.4

更新: 2026-09-15 / オーナー: 課金基盤

## 1. 解約の受付

- `cancel(subscription)`: 次回請求日の前日まで受け付ける。受付後、サブスクリプションは `CANCEL_REQUESTED` になる。
- 受付時刻の判定はサーバのタイムゾーン（Asia/Tokyo）で行う。
- ユーザーは受付を撤回できない。

## 2. 請求

- `CANCEL_REQUESTED` のサブスクリプションには、次回請求日以降の請求を行わない。
- 返金は finance の返金ポリシー（社外秘・別リポジトリ）に従う。

## 3. プラン変更との関係

- アップグレードと解約は同時に受け付け得る。

## 4. 観測

- 解約の受理/拒否と、請求が発生したかどうかが外部から観測できる。
