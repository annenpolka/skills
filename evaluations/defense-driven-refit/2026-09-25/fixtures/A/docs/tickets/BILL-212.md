# BILL-212 年額プランの自動更新

## 背景

年額プランの更新はこれまで CS が手動で請求していた。これを自動化する。

## 要求

1. `renews_at` を過ぎた active な年額購読を自動で更新課金する。
2. 同じ購読の同じ請求期間について二重に課金しない（利用規約 §4.2 に明記済み）。
3. 課金に失敗したら3日後に再試行する。連続3回失敗したら status を `past_due` にし、顧客へメールで通知する。
4. 請求額は税込。税率は config の `TAX_RATE`。通貨ごとの最小単位に丸める（JPY は1円、USD は1セント）。
5. 次回更新日は前回更新日の1年後とする。

## 規模

- 年額購読は約180万件。
- 2025年のキャンペーンの影響で、毎月1日に約40万件の更新が集中する。

## 対象外

- 月額プラン（既存の `monthly_worker` が担当）
- 返金
