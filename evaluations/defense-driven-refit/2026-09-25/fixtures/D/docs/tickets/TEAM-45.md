# TEAM-45 チーム機能の改善

## 要求

1. メンバー一覧の表示が遅いという問い合わせが多い。速くする。
2. プランの席数（`plans.seat_limit`）を超えてメンバーを招待できないようにする。席数には有効なメンバーと未承諾の招待を数える。
3. 招待メールに招待元の組織のロゴを表示する。ロゴは組織設定で管理者が登録した画像 URL を使う。
4. 表示名と本名を分ける準備として、`users.name` を `users.display_name` に改名する。

## 補足

- 管理者は一括招待画面から最大200件まで招待できる。画面は1件ずつ招待 API を呼ぶ（既存の動作）。
