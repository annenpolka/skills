# kinsoku（禁則）

組版エンジンは意見を持たない。行頭に句読点を置かないという禁則が先にあり、
追い込みと追い出しはそれを守るためにだけ動く。このskillは同じ構造を意味に適用する。

**禁則が先、変換は後。変換は禁則に仕える。**

許される失敗は「何もしなかった」だけ。「やりすぎた」は常に違反であり、
無変更（no-op）は正常な出力である。

## モード境界

kinsokuは既定の編集動作ではない。**入場は明示的、適用範囲は入場中の対象に限る。**

**入場**
- 「kinsoku」単体の発言
- 「kinsokuで」＋動詞＋本文（入場と依頼を一文にできる。以後これを標準の呼び出しとする）

**「禁則」という語自体は入場の合図にしない。** skill名の由来は組版の禁則処理
だが、「禁則」は組版・法律・このskill自身の説明など、通常の日本語語彙として
使われ続ける語。この語だけで入場できてしまうと、その語彙を丸ごと会話から
奪うことになる。入場の鍵は、通常の文に紛れ込まない"kinsoku"というトークン
だけが持つ。

**継続と退場**
同一会話・同一対象への後続の変換動詞・診断動詞の依頼は、明示的な退場
（「kinsoku終了」「普通に」等）がない限り入場中として扱う。対象が別の
文書・別の話題へ移った場合、新しい対象への言及は継続とみなさない
——そこは新たに入場するかどうかの判断がいる。

**入場していない場合**
裸の「整えて」「短くして」等、および「禁則」という語を含むだけの発言は
このskillの対象外。通常のClaudeの判断に委ねる。以下の禁則・T操作定義・
自己検査は、入場していない会話には適用しない。

## 相互作用クラス

クラスは発話の**形状**で決める。本文の意図を解釈してクラスを決めない。

| クラス | 形状 | 出力 |
|---|---|---|
| T（変換） | 変換動詞＋対象テキスト | 変換結果のみ。no-op可 |
| D（診断） | 診断動詞（点検して等）＋対象 | 所見のみ。変更しない |
| C（会話） | 上記以外すべて | 通常会話 |

動詞の判別:

- 変換の性質（整えて・直して・読みやすくして・短くして・削って・整理して・
  分けて・展開して・明文化して・続けて・補って）→ T。どの操作か不確かなら**下位へ丸める**（床は整形）
- 生成・評価・相談の性質（考えて・提案して・決めて・どう思う）→ C
- 判別不能 → Tとして扱い、下へ丸める。**曖昧さは決して生成に転ばない**

クラス間の暗黙昇格は禁止。動詞はT操作集合内の選択にだけ使い、Cへの扉を開かない。
上方向への丸めは常に違反。

## 禁則

全クラス共通。他の規定と衝突したら禁則が勝つ。

1. **対象の外に書かない。** 周辺文脈（read set）は理解にのみ使う。そこから主張・
   評価・論点を編集対象へ持ち込まない。許されるのは展開・補完での語彙の借用だけ。
2. **禁則トークンに触れない。** 次の級は、節ごとの移動と表記統一のみ可。
   追加・削除・強化・弱化・級間の交換は禁止:
   - 否定（ない/ぬ/ず/わけではない）
   - モダリティ・確信度（かもしれない/だろう/はず/と思う）
   - 数量・範囲（すべて/一部/だけ/ほとんど）
   - 条件・譲歩（なら/ば/場合/ても）
   - 逆接・留保（が/けれど/ただし）
   - 義務・許可・意志（べき/てよい/つもり）
   - 数値・固有名詞・引用
3. **固有名詞は誤記でも直さない。** 指摘はDで行う。
4. **問いを再定義しない。** 依頼された操作以外を行わない。
5. **頭と尻の禁則。** T・Dの出力冒頭に前置き・挨拶・復唱を置かない。
   末尾に講評・提案・質問・次の誘いを置かない。
6. **独自記法を出力に露出しない。** 内部の分類・検査の痕跡を残さない。
7. **権限を持ち越さない。** Cで解禁された生成・評価の権限は当該応答で失効する。
8. **「意味を変えない」を判断基準に使わない。** 検証不能な標語は規則ではない。
   基準は常に検証可能な代理——範囲・禁則トークン・文境界・語彙閉包——だけ。

## T操作（閉集合）

この五つで全部。実行時に増えない。

**整形** — 文内のみ: 助詞、活用、表記、句読点、明白な誤字。
文の結合・分割・削除・並べ替えは禁止。文数を保存し、出力文は入力文と1対1対応する。

**圧縮** — 削除と結合を解禁。全主張と禁則トークンを保持したまま短くする。
目標長の指定があれば従う。

**整理** — 並べ替えと階層化を解禁。アウトライン形式への再配置。
項目は入力の文（節）と1対1対応し、何も捨てない（削除は圧縮の領分）。
見出し・グループ名は入力の既出語彙に限る（語彙閉包）。分類軸はユーザー指定が
あればそれのみ。親子関係は入力の明示的な手掛かり（語の反復・指示・列挙・接続）
から導けるものに限り、導けなければフラットに並べる。**階層の床はフラット。**
深さは3まで。素材はユーザーの入力のみ——AIの発話を混ぜるにはCでの明示解禁が要る。

**展開** — 対象に畳み込まれた内容の言語化。内容語は対象＋read setの既出語彙に限る
（**語彙閉包**）。新規の主張・例・比喩・論点・結論は禁止。

**補完** — 高確度で定まる最短の続き。1文以内。確信が低いほど短く、
定まらなければ**空出力**。語彙閉包に従う。

## D（診断）

出力は所見のみ。各所見は一行: `位置 / 種別 / 指摘`。
修正文を書かない。「こう直すべき」は修正であって所見ではない。

種別: **矛盾 / 曖昧 / 欠落 / 表記 / 韓愈**

韓愈＝無許可の意味介入。原文にない主張の付与、確信度・義務の強度変更、
問いの再定義。原文と改稿の対が与えられた場合は、改稿側の韓愈を検出する。

## C（会話）

通常会話。課すのは二つだけ。

- 生成物に由来を付す: 対象由来 / 文脈由来 / 一般知識 / 類推
- 解禁された権限は当該応答で失効する

## 出力プロファイル

- 対象が1段落程度まで: 置換文のみ
- それ以上、または検証要求時: 変更断片のみ（変更前後の対）
- 「慎重に」の指定時: 生成 → 自己検査 → 違反なら縮小して1回だけ再試行 →
  なお違反なら no-op

自己検査の項目（内部のみ。出力に出さない）:
範囲外diff / 禁則トークンの級別増減 / 文数と対応（整形） /
項目の全数対応とラベルの語彙閉包（整理） /
語彙閉包（展開・補完） / 頭と尻の禁句

## 例

**入場なしでは対象外**

```
（kinsoku未入場の会話中）
入力: この文章、短くして
```

kinsokuは発動しない。通常のClaudeとして、要約でも言い換えでも文脈に応じてよい。
「kinsokuで短くして」であれば、全主張と禁則トークンを保持したまま削るという
このskillの制約下に入る。同じ動詞でも、入場の有無で出力契約が変わる。

**「禁則」と言っただけでは入らない**

```
（kinsoku未入場の会話中）
入力: 日本語の禁則処理って、行頭に句読点を来させないみたいなやつだよね
```

「禁則」という語は含まれるが、"kinsoku"というトークンではない。
このskillは対象外。通常の会話として応答する。

**整形 — ほぼ何もしないのが正解の場合**

```
入力: 整えて
この設計はたぶん正しいと思うけど、パフォーマンスがやばいかもしれない、ので検証がいる

出力:
この設計はたぶん正しいと思うけど、パフォーマンスがやばいかもしれないので、検証がいる。
```

「たぶん」「と思う」「かもしれない」は禁則トークン。「やばい」の言い換えは
語彙への介入であり整形の外。直したのは読点の位置だけ。

**曖昧な依頼 — 床へ丸める**

```
入力: いい感じにして
（雑なメモ）
```

「いい感じ」は操作を特定しない → 整形として実行。内容は足さない。

**補完 — no-opが正解の場合**

```
入力: 続けて
認証まわりは

出力: （なし）
```

高確度で定まる続きが存在しない。空出力は失敗ではない。

**整理 — 軸を発明しない**

```
入力: 整理して
ローカルLLMは速さ優先。禁則トークンの検査はスクリプトで。速いモデルは4Bか。検査は級別の増減を見る

出力:
- ローカルLLM
  - 速さ優先
  - 速いモデルは4Bか
- 禁則トークンの検査
  - スクリプトで
  - 級別の増減を見る
```

グループ名は入力の語だけ。「技術選定」「品質保証」のような軸の発明はしない。
導けない関係はフラットのまま。

**韓愈の検出**

```
入力: 点検して
原文: リモート可否は足切り条件にしたい
改稿: リモート可否を最優先の評価軸とすべきだ

出力:
1文目 / 韓愈 / 願望「したい」が義務「べきだ」へ、足切り条件が最優先の評価軸へ変更されている
```

**悪い出力（頭と尻の禁則違反）**

```
承知しました。整えますね。
（変換結果）
さらに提案ですが、この段落は削除してもよいかもしれません。
```

頭に復唱、尻に提案。両方が違反。変換結果だけを返す。

---

品質の定義: どれだけうまく書いたかではなく、どれだけ越権しなかったか。
測るなら韓愈率——出力のうち韓愈をやった割合——であって、文章の巧拙ではない。
