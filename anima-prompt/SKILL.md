# anima-prompt

Animaは書かなかったものを描かない。ネガティブで祓うな、ポジティブで建てろ。

## モデル前提（このスキルが依拠する5つの性質）

1. Danbooru語と自然文の両方を読む。混合可
2. プロンプト忠実性が高い。未指定要素（特に背景）は無地になる
3. 前方のタグほど強く効く
4. テキストエンコーダはQwen3 0.6B。長文の理解力は高くない
5. ベースモデルは絵柄非固定。安定化は別レイヤーで行う

## Workflow

### 1. Intake

ユーザー入力から以下を抽出する。**質問はしない**。不足は補完し、仮定としてNotesに記す。

- 主題（人数・キャラ・外見） / 行為・ポーズ / 場所・背景 / 光・時間帯 / 画風・雰囲気 / レーティング

### 2. Mode選択

- **tag-led**（デフォルト）: タグ列＋末尾に短い自然文0〜3文
- **nl-led**: 関係性・物語性・位置関係が主のとき。先頭スロット（品質〜人数）のみタグ、
  以降を説明的な自然文2文以上で書く
- 判断基準: 「誰が誰に何をするか」が絵の核ならnl-led、静的な一枚絵ならtag-led

### 3. スロット組み立て

順序は固定。同一スロット内は順不同。

| # | スロット | 例 |
|---|---------|----|
| 1 | 品質/メタ/年代/レーティング | masterpiece, best quality, newest, safe |
| 2 | 人数（＋関係性） | 1girl / 2girls, duo, holding hands |
| 3 | キャラクター名 | ユーザー指定時のみ |
| 4 | シリーズ名 | ユーザー指定時のみ |
| 5 | アーティスト | @artist name（指定時のみ・@必須） |
| 6 | 一般タグ→自然文 | 外見→服→ポーズ→表情→構図→**背景→光**（後半に置く） |

タグ語彙の選択は `references/anima-conventions.md` の辞書を参照する。

### 4. Lint（出力前チェック）

- [ ] レーティングタグがちょうど1つあるか（無指定ならsafe。勝手に格上げしない）
- [ ] @なしのアーティスト名、アンダースコア入り@タグが混入していないか
- [ ] 背景・光の指定があるか（なければ補完し、Notesに仮定として書く）
- [ ] 同一部位への矛盾指示がないか（タグ↔自然文の間も見る。矛盾はそのまま描かれる）
- [ ] 強調は重要タグ3個以内・重み0.4〜1.5の範囲か
- [ ] 画像内テキスト・ロゴの要求が残っていないか（小物・表情・演出タグに変換する）
- [ ] 複数キャラ: 人数タグ直後に関係性、各キャラは上から下（髪→目→服→靴）の順か

### 5. 出力

````
Positive:
<プロンプト>

Negative:
<ネガティブ>
````

- Notes: 補完した仮定と警告のみ、3行以内。解説はしない
- 設定値（解像度/CFG/Steps）はユーザーが求めたときだけ添える

## 修正プロトコル（生成結果が崩れたとき）

1. まず確認: **Turbo系LoRAを使っていないか**。CFG1でネガティブが無効化し挙動が別物になる。
   相談・比較の前提として必ずTurbo有無を切り分ける
2. 1回の修正で動かす変数は1系統のみ（タグ追加 / 重み変更 / ネガ追加を同時にやらない）
3. ネガティブへの追加は、観測されたfailure mode 1つにつき最大2タグ
4. 絵柄が暴れる場合の対処優先順:
   派生モデル > 絵柄LoRA > @アーティスト > メジャー作品タイトル > 品質タグ重み0.7以下
