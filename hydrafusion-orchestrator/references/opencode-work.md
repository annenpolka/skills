# OpenCodeへの委譲

ユーザーがOpenCodeを指定した場合、インストール済み `opencode-delegate` を読み、そのhelperを使って実装役を割り当てる。

1. 現在の依頼や既存の承認で指定された正確な `provider/model` を使う。可用性が不明な場合は確認する。
2. 目的、作業場所、編集範囲、制約、完成条件を短い依頼書にまとめる。
3. helperの `--cd`、`--model`、`--agent build`、`--brief` で実装を委譲する。権限とtimeoutは `opencode-delegate` の手順に従う。
4. 終了後に `result.json` と実際の差分を読み、必要な確認を実行する。
5. 修正が必要なら、返されたsession IDと同じモデルを指定し、変更点だけを伝えて再開する。

既存のユーザー変更や同時作業と衝突する場合は別checkoutを使う。権限エラーが起きた場合は、必要な作業範囲と許可設定を確認して処理する。
